# Pixel Guess
Pixel Guess é um jogo de adivinhação visual em que os jogadores precisam descobrir o que está escondido por trás de uma imagem desfocada, desbloqueando novas pistas e fragmentos da imagem a cada tentativa até encontrar a resposta correta.
